# Виртуальные очереди (virtual queues)

Сервис восстанавливает виртуальные очереди к станциям по телеметрии машин и рекомендует перенаправлять машины в менее загруженные станции. Реализовано на Python (Kafka, `confluent-kafka`).

## Требования

- Docker + Docker Compose
- (опционально) Python 3.11+ для локального запуска тестов
- (опционально) Kafka локально (если запускать без Docker)

## 🚀 Запуск (Docker, всё одной командой)

```bash
docker compose up -d
